03 / CLASSICAL CRYPTOGRAPHY
RSA: the classical reference point
A compact example of number theory, modular arithmetic and trapdoor functions.
QUANTUMSHIELD LAB
04
KEY GENERATION
n = p × q
φ(n) = (p − 1)(q − 1)
gcd(e, φ(n)) = 1
e × d ≡ 1  (mod φ(n))
TEXTBOOK MODEL
Encrypt:  c = mᵉ mod n
Decrypt:  m = cᵈ mod n
SECURITY NOTE
Toy equations explain the idea; they are not a secure implementation. Real RSA uses secure schemes such as OAEP for encryption and PSS for signatures.
RSA's classical security is tied to the difficulty of factoring appropriately sized integers.

=== ppt/slides/slide5.xml ===
04 / THREAT MODEL
Quantum algorithms change the assumptions
QUANTUMSHIELD LAB
05
SHOR'S ALGORITHM
• Efficiently solves integer factorization and discrete logarithms in the quantum model.
• Threatens RSA and elliptic-curve cryptography.
• Practical impact depends on a sufficiently capable fault-tolerant machine.
GROVER'S ALGORITHM
• Gives a quadratic speedup for idealized unstructured search.
• Implications differ from Shor's impact on public-key systems.
• Does not mean every cryptographic algorithm is broken in the same way.
THEORY ≠ CURRENT CAPABILITY   ·   Hardware scale, error correction and resources matter.

=== ppt/slides/slide12.xml ===
11 / CRYPTOGRAPHIC LOGIC
Digital signatures · integrity and authenticity
QUANTUMSHIELD LAB
12
ML-DSA
Module-lattice-based signature standard.

Private key + message → signature
Public key + message + signature → valid / invalid
SLH-DSA
Stateless hash-based signature standard.

Alternative mathematical approach based on cryptographic hash functions.
TAMPER TEST
Change one message byte → verification should fail.
A signature supports integrity and authenticity; it does not encrypt the message.
